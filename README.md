# 三國鼎立（3D 三國戰略遊戲）

瀏覽器 3D 遊戲（three.js r160，ES modules，從 CDN 載入，不需安裝 Node）。

## 執行

```
python3 serve.py        # 開啟 http://localhost:8123
```

## 檔案

- `js/main.js`：畫面流程（標題、選勢力、地圖 HUD）、劇情腳本執行器、天下征戰（出兵、敵國來犯、季度收入）
- `js/worldmap.js`：立體天下地圖：依經緯度生成地形（秦嶺、太行、青藏高原、四川盆地…）、長江黃河等河流湖泊、海岸線、城池模型、疆域著色（戰後即時重繪）、行軍動畫
- `js/battle.js`：3D 戰場：平原／山地／攻守城地形、林地與營寨、部隊模擬、陣型、兵種相剋、兵法、伏兵、雲梯衝車霹靂車、陣前會談與單挑、乘勝追擊／撤退／求和／背水一戰、戰果與俘虜處置
- `js/story.js`：魏、蜀、吳三條主線（各 5～6 章，17 場劇情戰），依《三國志》史實並有分支
- `js/data.js`：勢力、武將、城池（真實經緯度）、道路、兵法、兵器、陣型、兵種
- `js/state.js`：遊戲狀態與存檔（localStorage）
- `js/figures.js`：精細人物系統：參數化人體（甲冑、衣袍、披風、五官、鬍鬚、冠帽）、戰馬、四輪車、各式兵器；約 50 位主要人物的專屬造型、離屏渲染 3D 頭像、人物圖鑑檢視器；批次士兵也用同一套建模
- `js/models.js`：旗幟、樹木、城池、城牆、營帳、投石車等場景模型
- `js/ui.js`、`js/audio.js`：對話／選擇／彈窗介面、合成音效

除錯：瀏覽器主控台的 `window.SGZ` 可存取 state、doBattle、STORY 等。
